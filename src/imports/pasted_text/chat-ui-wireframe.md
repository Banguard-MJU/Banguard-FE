좋아. 바로 옮겨 그릴 수 있게 **저충실도(low-fidelity)*와이어프레임**으로 정리할게.
기준은 **ChatGPT 스타일 + React/Tailwind 구현에 맞는 구조**야.

# 2. 빈 화면 상태 와이어프레임

처음 진입했을 때 가장 중요한 상태야.

```text
┌──────────────────────────────────────────────────────────────┐
│ Top Bar: Bot name / Model                         [⋯]        │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                        App Logo / Icon                       │
│                      "무엇을 도와드릴까요?"                   │
│                                                              │
│        ┌────────────────────┐  ┌────────────────────┐        │
│        │ 예시 질문 1         │  │ 예시 질문 2         │        │
│        └────────────────────┘  └────────────────────┘        │
│        ┌────────────────────┐  ┌────────────────────┐        │
│        │ 예시 질문 3         │  │ 예시 질문 4         │        │
│        └────────────────────┘  └────────────────────┘        │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ [+]  메시지를 입력하세요                              [↑]     │
└──────────────────────────────────────────────────────────────┘
```

이 상태에서 필요한 포인트:

* 서비스 설명 한 줄
* 추천 프롬프트 카드 4개
* 입력창 하단 고정
* 사이드바에서는 최근 대화만 보여주기

# 3. 대화 진행 상태 와이어프레임

실제로 가장 오래 머무는 화면이야.

````text
┌──────────────────────────────────────────────────────────────┐
│ Top Bar                                                     │
│ [Sidebar toggle]  GPT Assistant / GPT-4.1         [Share][⋯]│
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  User message                                                │
│  ┌────────────────────────────────────────────────────────┐   │
│  │ ChatGPT 스타일 챗봇 UI 와이어프레임 만들어줘         │   │
│  └────────────────────────────────────────────────────────┘   │
│                                                              │
│  Assistant message                                           │
│  ┌────────────────────────────────────────────────────────┐   │
│  │ 아래처럼 잡으면 좋아요...                             │   │
│  │                                                        │   │
│  │ - 사이드바                                             │   │
│  │ - 메인 채팅                                            │   │
│  │ - 입력창                                               │   │
│  │                                                        │   │
│  │ ```tsx                                                 │   │
│  │ <ChatLayout />                                         │   │
│  │ ```                                                    │   │
│  └────────────────────────────────────────────────────────┘   │
│   [Copy] [Edit] [Regenerate] [👍] [👎]                       │
│                                                              │
│  Assistant typing...                                         │
│  ● ● ●                                                       │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ [+] Message input...                                  [Stop] │
│ Attachments preview / prompt tools / character helper        │
└──────────────────────────────────────────────────────────────┘
````

핵심:

* 사용자 메시지는 상대적으로 심플
* AI 메시지는 넓고 읽기 좋게
* 메시지 액션 버튼은 hover 시 노출
* 생성 중엔 `Stop`이 `Send`를 대체

# 4. 모바일 와이어프레임

모바일에서는 사이드바가 드로어로 바뀌는 게 핵심이야.

```text
┌──────────────────────────────┐
│ [☰] GPT Assistant      [⋯]   │
├──────────────────────────────┤
│                              │
│ User message                 │
│ ┌──────────────────────────┐ │
│ │ 챗봇 UI 구조 보여줘      │ │
│ └──────────────────────────┘ │
│                              │
│ Assistant                    │
│ ┌──────────────────────────┐ │
│ │ 아래 구조로 시작하면     │ │
│ │ 좋아요...                │ │
│ └──────────────────────────┘ │
│ [Copy] [Retry]               │
│                              │
│                              │
├──────────────────────────────┤
│ [+] 메시지 입력...       [↑] │
└──────────────────────────────┘
```

모바일 드로어 열림 상태:

```text
┌──────────────────────────────┐
│ Sidebar Drawer               │
│──────────────────────────────│
│ [ + New chat ]               │
│ [ Search conversations ]     │
│                              │
│ Today                        │
│ - UI wireframe               │
│ - React layout               │
│                              │
│ Yesterday                    │
│ - Prompt ideas               │
│                              │
│ [Settings] [Profile]         │
└──────────────────────────────┘
```

모바일 주의점:

* 입력창은 키보드에 가리지 않게 `sticky bottom`
* 긴 메시지는 자동 높이 증가
* 액션 버튼은 아이콘 위주
* 메시지 bubble padding 축소

# 5. 꼭 필요한 화면 단위

와이어프레임을 실제 설계할 때는 아래 6개 화면만 잡아도 시작 가능해.

## A. Empty State

첫 진입 화면

## B. Conversation State

메시지가 쌓인 일반 상태

## C. Generating State

AI가 답변 생성 중인 상태

## D. Error State

네트워크/응답 실패

```text
┌────────────────────────────────────────────┐
│ 응답을 불러오지 못했습니다                 │
│ [다시 시도] [이전 메시지 수정]             │
└────────────────────────────────────────────┘
```

## E. Attachment State

파일 업로드 직후 상태

```text
┌────────────────────────────────────────────┐
│ [pdf-icon] report.pdf                  [x] │
│ [img-thumb] screenshot.png             [x] │
└────────────────────────────────────────────┘
│ 메시지를 입력하세요...                      │
```

## F. Settings Modal

설정은 전체 페이지보다 오른쪽 슬라이드 패널이 더 자연스러워.

```text
┌──────────────────────────────┐
│ Settings                 [x] │
├──────────────────────────────┤
│ Theme        [Dark / Light ] │
│ Language     [한국어      ▼ ] │
│ Enter to send [ On / Off   ] │
│ History      [ On / Off   ] │
│ Model        [ GPT-4.1   ▼ ] │
│ Memory       [ On / Off   ] │
└──────────────────────────────┘
```

# 7. Tailwind로 바로 옮기기 쉬운 레이아웃 기준

## 데스크톱

* `Sidebar`: `w-72 border-r`
* `Main`: `flex-1 flex flex-col`
* `Header`: `h-14 border-b`
* `MessageList`: `flex-1 overflow-y-auto`
* `Composer`: `sticky bottom-0 border-t`

## 전체 골격

```text
min-h-screen
flex
bg-background
text-foreground
```

## 메시지 영역 폭

* 전체는 넓게 두되
* 실제 텍스트는 `max-w-3xl mx-auto`
* 가독성을 위해 너무 넓지 않게 제한

---

# 8. 실제 배치 치수 추천

와이어프레임 단계에서 잡기 좋은 값이야.

* 사이드바 폭: `280px`
* 메인 메시지 최대 폭: `768px ~ 896px`
* 헤더 높이: `56px`
* 입력창 최소 높이: `56px`
* 메시지 간격: `16px`
* 섹션 패딩: `24px`
* 모바일 좌우 패딩: `16px`

---

# 9. 가장 추천하는 최종 구조

처음 만들 때는 아래 3단만 잡으면 돼.

```text
[Sidebar]
  └ 최근 대화 / 새 채팅 / 설정

[ChatPanel]
  ├ Header
  ├ Messages
  └ Composer
```

여기에 나중에만 추가:

* 파일 첨부
* 모델 선택
* 음성 입력
* 설정 패널
* 공유 기능

# 10. 바로 피그마에 옮길 수 있는 프레임 이름

정리해서 그대로 프레임명으로 써도 돼.

* `Chat / Desktop / Empty`
* `Chat / Desktop / Conversation`
* `Chat / Desktop / Generating`
* `Chat / Desktop / Error`
* `Chat / Mobile / Empty`
* `Chat / Mobile / Conversation`
* `Chat / Settings / Panel`

원하면 다음 답변에서 이 와이어프레임을 바로 **React + Tailwind 컴포넌트 구조도**로 바꿔서 줄게.
